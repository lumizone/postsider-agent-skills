# PostSider

When asked to schedule, publish, or review social media posts, or to check
PostSider analytics, use the `postsider` MCP tools.

- Auth and capabilities: https://github.com/lumizone/postsider-agent-skills/blob/main/core/auth.md
- Tool reference: https://github.com/lumizone/postsider-agent-skills/blob/main/core/tools-reference.md
- Task playbooks: https://github.com/lumizone/postsider-agent-skills/blob/main/core/workflows.md

Follow the matching playbook in https://github.com/lumizone/postsider-agent-skills/blob/main/core/workflows.md step by step. Never
publish or delete a post without the user confirming content and target
channel in this session.
